# Music Folder

Add your song file here as `song.mp3` to have it play automatically on the gallery page.

**Supported formats:**
- `.mp3` (recommended)
- `.wav`
- `.ogg`

Just rename your file to `song.mp3` and place it in this folder, then reload the gallery page!

The music will:
- ⏯️ Autoplay when the page loads
- 🔊/🔇 Have a mute/unmute button in the bottom-right corner
- 🔁 Loop continuously
