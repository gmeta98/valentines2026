# Valentine's Day 2026 💖

An interactive Valentine's Day card built with Streamlit! This fun web application features a playful "Will you be my Valentine?" prompt with a twist - the "No" button runs away when you try to click it!

## Features

- 🎯 Interactive buttons with smooth animations
- 😄 Funny messages as you try to catch the "No" button
- 💝 Beautiful gradient background
- 📱 Responsive design that works on desktop and mobile
- ✨ Engaging user experience with hover and click effects

## How It Works

1. The app displays a Valentine's card with two buttons: "Yes" and "No"
2. The "Yes" button is easy to click and shows a sweet message when clicked
3. The "No" button playfully moves away when your cursor gets close, making it nearly impossible to reject!
4. Random funny messages appear at the bottom as you chase the "No" button

## Installation

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Setup

1. Clone the repository:
```bash
git clone https://github.com/gmeta98/valentines2026.git
cd valentines2026
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the Streamlit app:
```bash
streamlit run app.py
```

The app will open in your default web browser at `http://localhost:8501`

## Deployment

### Streamlit Cloud

1. Push your code to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Sign in with GitHub
4. Deploy the app by selecting your repository

### Other Platforms

This app can also be deployed on:
- Heroku
- Google Cloud Platform
- AWS
- Any platform that supports Python and Streamlit
